# 个人收支记账系统 - 测试操作步骤

## 环境要求

- JDK 8 或以上
- Maven 3.6+

## 启动步骤

### 1. 进入项目目录
```bash
cd accounting-system
```

### 2. 编译项目
```bash
mvn clean package -DskipTests
```

### 3. 运行项目
```bash
java -jar target/accounting-system-1.0.0.jar
```

或者使用 Maven 直接运行：
```bash
mvn spring-boot:run
```

### 4. 访问系统
启动成功后，在浏览器中访问：
```
http://localhost:8088
```

## 功能测试步骤

### 一、用户注册与登录测试

#### 1. 用户注册
1. 打开浏览器访问 `http://localhost:8088`
2. 点击"没有账号？立即注册"
3. 输入注册信息：
   - 账号：`13800138000`（手机号格式）
   - 密码：`123456`
   - 昵称：`测试用户`
4. 点击"注册"按钮
5. 预期结果：提示"注册成功，请登录"

#### 2. 用户登录
1. 在登录页面输入：
   - 账号：`13800138000`
   - 密码：`123456`
2. 点击"登录"按钮
3. 预期结果：登录成功，跳转到主页面，显示用户昵称

#### 3. 测试账号格式校验
1. 尝试使用错误格式的账号注册（如：`abc`）
2. 预期结果：提示"账号格式不正确"

#### 4. 测试密码长度校验
1. 尝试使用短密码注册（如：`123`）
2. 预期结果：提示"密码长度必须在6-20位之间"

---

### 二、记账功能测试

#### 1. 添加支出记录
1. 登录后，点击"+ 添加记录"按钮
2. 填写记录信息：
   - 金额：`50`
   - 类型：选择"支出"
   - 分类：选择"餐饮"
   - 备注：`午餐`
3. 点击"保存"按钮
4. 预期结果：记录添加成功，列表中显示新记录

#### 2. 添加收入记录
1. 点击"+ 添加记录"按钮
2. 填写记录信息：
   - 金额：`5000`
   - 类型：选择"收入"
   - 分类：选择"薪资"
   - 备注：`3月工资`
3. 点击"保存"按钮
4. 预期结果：记录添加成功

#### 3. 测试金额校验
1. 尝试添加金额为0或负数的记录
2. 预期结果：提示"金额必须为正数"

#### 4. 测试分类校验
1. 尝试选择收入类型后，选择支出分类
2. 预期结果：系统会自动更新分类选项

#### 5. 修改记录
1. 找到一条记录，点击"编辑"按钮
2. 修改金额为 `100`
3. 点击"保存"按钮
4. 预期结果：记录修改成功，显示新金额

#### 6. 删除记录
1. 找到一条记录，点击"删除"按钮
2. 确认删除
3. 预期结果：记录删除成功，列表中不再显示

---

### 三、查询功能测试

#### 1. 按类型筛选
1. 在筛选区域，选择类型"支出"
2. 预期结果：列表只显示支出类型的记录

#### 2. 按分类筛选
1. 选择分类"餐饮"
2. 预期结果：列表只显示餐饮分类的记录

#### 3. 按时间范围筛选
1. 选择开始日期和结束日期
2. 预期结果：列表只显示该时间范围内的记录

#### 4. 分页测试
1. 添加超过10条记录
2. 查看分页是否正常工作
3. 点击"下一页"或页码
4. 预期结果：正确显示对应页的数据

---

### 四、统计功能测试

#### 1. 查看周统计
1. 点击顶部导航的"统计"标签
2. 查看"本周统计"区域
3. 预期结果：显示本周的收入、支出、结余金额

#### 2. 查看月统计
1. 查看"本月统计"区域
2. 预期结果：显示本月的收入、支出、结余金额

#### 3. 查看分类统计
1. 在分类统计区域，选择类型"支出"
2. 预期结果：显示各支出分类的金额和占比
3. 分类条形图应正确显示比例

---

### 五、修改密码测试

#### 1. 修改密码
1. 点击顶部导航的"我的"标签
2. 输入：
   - 原密码：`123456`
   - 新密码：`654321`
   - 确认新密码：`654321`
3. 点击"修改密码"按钮
4. 预期结果：提示"密码修改成功"

#### 2. 验证新密码
1. 退出登录
2. 使用新密码登录
3. 预期结果：登录成功

---

### 六、权限测试

#### 1. 未登录访问
1. 清除浏览器缓存或使用隐私模式
2. 直接访问 `http://localhost:8088`
3. 预期结果：显示登录页面

#### 2. Token失效
1. 登录后，在开发者工具中修改localStorage中的token为无效值
2. 刷新页面或进行操作
3. 预期结果：提示"请先登录"，跳转到登录页面

## 数据存储验证

### 查看 CSV 文件
系统运行后，会在项目根目录下创建 `data` 文件夹，包含：
- `users.csv` - 用户数据
- `records.csv` - 记账记录数据

可以用文本编辑器打开查看数据是否正确存储。

## 常见问题

### 1. 端口被占用
如果8088端口被占用，可以修改 `application.yml` 中的端口号：
```yaml
server:
  port: 8089
```

### 2. 数据文件位置
数据文件默认存储在 `./data` 目录，可在 `application.yml` 中修改：
```yaml
app:
  data:
    path: ./data
```
