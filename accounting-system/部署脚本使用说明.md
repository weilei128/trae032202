## 二、自动化部署脚本说明

### 脚本文件列表

| 文件 | 说明 |
|------|------|
| `deploy_automation.ps1` | 完整的自动化部署脚本（PowerShell） |
| `deploy.ps1` | 简化版部署脚本 |
| `Dockerfile` | Docker 镜像构建文件 |

### deploy_automation.ps1 功能特性

1. **配置自动检查与更新**
   - 自动检查并更新 `application.yml` 端口配置
   - 自动检查并更新 `pom.xml` 配置（Java版本、jar包名称）

2. **智能打包**
   - 自动执行 Maven 打包（跳过测试）
   - 支持跳过已存在的jar包（加速部署）

3. **服务器环境检测**
   - SSH 连接测试
   - Docker 环境检测与自动安装
   - 目标目录自动创建

4. **自动部署**
   - 文件上传（jar包 + Dockerfile）
   - Docker 镜像自动构建
   - 端口占用自动检测与处理
   - 旧容器与旧镜像自动清理

5. **服务验证**
   - 容器状态检查
   - 服务可用性检测
   - 访问地址输出

## 三、快速重新部署

### 方式一：使用完整自动化脚本
```powershell
# 进入项目目录
cd accounting-system

# 执行完整自动化部署
.\deploy_automation.ps1
```

### 方式二：分步手动执行（如需调试）
```powershell
# 1. 打包（如已打包可跳过）
mvn clean package -DskipTests

# 2. 上传文件
scp -P 22 target/dogFooding.jar root@49.235.161.106:/opt/apps/memo-app/
scp -P 22 Dockerfile root@49.235.161.106:/opt/apps/memo-app/

# 3. 远程部署
ssh -p 22 root@49.235.161.106 '
cd /opt/apps/memo-app
docker build -t accountingtest-app:1.0.0 .
docker rm -f accountingtest-app
docker run -d --name accountingtest-app --restart=always -p 10011:10011 -v /opt/apps/memo-app/data:/app/data accountingtest-app:1.0.0
'
```

## 四、服务器端常用管理命令

### 容器管理
```bash
# 查看容器状态
docker ps --filter name=accountingtest-app

# 查看容器日志
docker logs accountingtest-app          # 查看全部日志
docker logs -f accountingtest-app       # 实时查看日志
docker logs --tail 50 accountingtest-app  # 查看最后50行

# 容器操作
docker restart accountingtest-app       # 重启容器
docker stop accountingtest-app          # 停止容器
docker start accountingtest-app         # 启动容器
docker rm -f accountingtest-app         # 删除容器（强制）
```

### 镜像管理
```bash
# 查看镜像
docker images accountingtest-app

# 删除旧镜像
docker rmi accountingtest-app:1.0.0
```

### 服务验证
```bash
# 本地验证（服务器端）
curl http://localhost:10011/

# 查看资源使用
docker stats --no-stream accountingtest-app
```

### 数据目录
```bash
# 应用数据存储位置（宿主机）
cd /opt/apps/memo-app/data
ls -la

# 查看容器内数据
docker exec accountingtest-app ls -la /app/data
```

## 五、故障排查

### 常见问题

1. **容器无法启动**
   ```bash
   # 查看详细错误日志
   docker logs accountingtest-app
   
   # 检查端口是否被占用
   netstat -tlnp | grep 10011
   ```

2. **服务访问超时**
   - 检查防火墙/安全组规则（确保10011端口开放）
   - 检查容器是否正常运行：`docker ps`
   - 检查应用日志：`docker logs accountingtest-app`

3. **重新构建镜像**
   ```bash
   cd /opt/apps/memo-app
   docker build --no-cache -t accountingtest-app:1.0.0 .
   ```

## 六、配置更新流程

如需修改应用配置，按以下步骤重新部署：

1. **修改本地配置文件**
   - `src/main/resources/application.yml` （修改端口或其他配置）
   - `pom.xml` （修改依赖或项目配置）

2. **重新打包并部署**
   ```powershell
   .\deploy_automation.ps1
   ```

3. **或手动执行**
   ```powershell
   mvn clean package -DskipTests
   scp -P 22 target/dogFooding.jar root@49.235.161.106:/opt/apps/memo-app/
   ssh -p 22 root@49.235.161.106 'docker restart accountingtest-app'
   ```

## 八、注意事项

1. **密钥认证**：确保本地SSH密钥已添加到服务器的 `~/.ssh/authorized_keys`

2. **端口冲突**：脚本会自动检测并处理10011端口的占用，但如果有其他重要服务在该端口，需手动调整

3. **数据持久化**：容器的 `/app/data` 目录已映射到宿主机的 `/opt/apps/memo-app/data`，数据不会因容器重建而丢失

4. **防火墙**：确保服务器防火墙和云服务商安全组已开放10011端口的入站规则

5. **资源限制**：当前JVM配置为 `-Xms256m -Xmx512m`，如需调整可修改 `Dockerfile` 中的 `ENTRYPOINT` 指令
